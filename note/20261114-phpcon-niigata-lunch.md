# PHPカンファレンス新潟2026 お昼休みの楽しみ方 〜お弁当・スポンサーLT・アンカンファレンス〜

こんにちは。PHPカンファレンス新潟2026 コアスタッフのおさないです。

11月14日（土）のPHPカンファレンス新潟2026では、お昼休みを **12:10〜14:10 の2時間** とっています。
ただの休憩ではなく、お弁当を食べながら聞ける企画や、その場でテーマを出し合う企画を用意しました。
この記事では、お昼休みの過ごし方を紹介します。

## お昼休みのタイムテーブル

| 時間 | 内容 |
|---|---|
| 12:10〜 | 昼休憩・お弁当の配布 |
| 12:20〜12:50 | スポンサーLT・エレベーターピッチ |
| 13:00〜14:00 | アンカンファレンス・OST（Open Space Technology） |
| 14:10〜 | 午後のセッション開始 |

ランチは、新潟駅の駅弁でおなじみの **新潟三新軒** 様のお弁当です。
お弁当は参加チケットに含まれているので、追加の料金はかかりません。

- 村上牛しぐれ

新潟のお米と海の幸、新潟県村上市のブランド牛「村上牛」を、会場で味わってください。

## 12:20〜12:50 スポンサーLT・エレベーターピッチ

お弁当を食べながら、スポンサー企業の **LT** と **エレベーターピッチ** を聞けます。

PHPカンファレンス新潟は、スポンサーのみなさまの協賛で成り立っています。
各社がどんなサービスをつくっているのか、どんな技術を使っているのかを短い時間で知れるので、ぜひ耳を傾けてみてください。
気になった会社があれば、休憩中や懇親会で声をかけてみるのもおすすめです。

## 13:00〜14:00 アンカンファレンス・OST

お昼の後半は、**アンカンファレンス** と **OST（Open Space Technology）** です。

どちらも、決まった登壇者やテーマがない企画です。参加者がその場で話したいテーマを出し合い、興味のある輪に自由に加わります。

- 午前のセッションで気になったことを、もう少し深く話したい
- 普段の仕事で悩んでいることを、ほかの人に聞いてみたい
- 新潟のエンジニア事情について話してみたい

こんな「ちょっと話したいこと」を持ってきてください。
テーマを出す人も、聴くだけの人も歓迎です。途中で別の輪に移っても大丈夫です。

## おわりに

お昼休みは、お弁当でおなかを満たしつつ、スポンサーや参加者のみなさんとつながれる時間です。
午前に知り合った人と一緒にお弁当を食べて、そのままアンカンファレンスに参加するのも楽しいと思います。

11月14日（土）、朱鷺メッセでお待ちしています！
