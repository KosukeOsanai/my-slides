# 調査メモ（20261021 PHP勉強会@東京 用）

発表テーマ: PHPカンファレンス新潟2026（2026/11/14 土）の徹底解説。
構成は 1. 概要 → 2. セッションの魅力（テーマ別 / タイプ別モデルルート）→ 3. セッション以外の魅力。

> 構成の参考: Vue Fes Japan 2026「タイムテーブル徹底解説」（448jp）
> <https://speakerdeck.com/448jp/vue-fes-japan-2026-taimu-teburu-tettei-kaisetsu>
> - 1章「Vue Fes Japan 2026とは」: アンケート → 章扉（英語サブタイトル）→ 開催概要 → タイムテーブル（1 Day, N Tracks）→ 会場 → 数字で見る
> - 2章「セッションをテーマ別に観る」: テーマごとに「時刻 → トラック → タイトル → 話者」を時刻順。LTは分けて表示
> - 3章「タイプ別モデルルート」: ルート一覧（ラベル＋1行説明）→ 1ルート1枚で1日の時系列
> - 4章「セッション以外の楽しみ方」: 企画・場所の紹介 → 事前にやること → 当日のコツ → 人とつながる
>
> 本デッキでは2章と3章を「2. セッションの魅力」にまとめ、4章を「3. セッション以外の魅力」にしている。

> **公式noteのセッション紹介記事（第1〜5弾）は未公開。** 内容は参照してよいが、URLは載せない。
